## कुन Technology उपयोगी हुन्छ?

यो project को लागि सबैभन्दा उपयुक्त technology भनेको **Scratch** नै हो, किनकि यसले beginner-friendly visual coding, drag-and-drop blocks, sprites, backdrops, variables, broadcasts, loops, र collision logic सजिलै सिकाउन सक्छ। Classroom र Smart Board demo का लागि पनि Scratch नै सबैभन्दा practical हुन्छ।

यदि goal केवल school project होइन, अझ real-time र polished car game बनाउने हो भने यी options पनि उपयोगी हुन्छन्:

• **Scratch** - step-by-step learning, simple game logic, quick classroom output
• **HTML5 + JavaScript + Canvas** - browser-based real game, custom graphics, smooth control
• **Phaser.js** - 2D game framework, collision, animation, scoring, mobile-friendly web game
• **Godot** - full game engine, better physics, scenes, sound, and exporting to multiple platforms

Best recommendation:

• **Beginner classroom version:** Scratch
• **Intermediate web game version:** HTML5 + JavaScript + Phaser.js
• **Advanced full game version:** Godot

यसरी technology choose गर्दा विद्यार्थीहरूको level, समय, र final output अनुसार projectलाई राम्रोसँग scale गर्न सकिन्छ।
