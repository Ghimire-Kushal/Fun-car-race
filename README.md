# Car Racing Game

This is a small browser-based racing game inspired by the Scratch classroom plan in `brain.md`.

## Run

Open `index.html` in a browser.

## Controls

- Left arrow or `A`: move left
- Right arrow or `D`: move right
- `Enter` or `Space`: start or restart

## Features

- Smooth lane-based car movement
- Scrolling road and lane markers
- Random traffic obstacles
- Coin and fuel pickups
- Score, time, level, fuel, and lives
- Speed increases as the level rises
- Game over and restart screen
